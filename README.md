# 🌸 Happy Birthday, Mom! (Mama's Birthday Surprise) ❤️

A personalized, interactive birthday surprise website created with love for **Jyoti Devi** by her son **Abhishek Kumar**.

---

## ✨ Features
- **Cinematic Welcome Scene:** Real framed photo with soft glow, floating petals, and animations.
- **Heartfelt Welcome Message:** Loving message honoring Mom.
- **Interactive Yes/No Interaction:** A playful No button with proximity-based dodge and cute Hindi messages (“अरे मम्मी, ये क्या! 😂”, “नहीं चलेगा, मम्मी जी! 😜”).
- **Midnight Lights & Sky Reveal:** Interactive fairy lights and sky ambiance.
- **Party Decoration & Flying Balloons:** Interactive party setup with release celebration.
- **3D Cake Cutting Ceremony:** Candle lighting and cake-cutting celebration.
- **Magical Gift Box:** Glowing 3D gift box with celebration effects.
- **Devanagari Typewriter Letter:** Emotional, loving Hindi birthday letter typed live with Noto Sans Devanagari typography.
- **Photo Memories Gallery:** Interactive family memory carousel.
- **Final Grand Surprise & Wish:** Grand celebration finale with audio soundtrack.
- **Background Music:** Seamless audio playback with mute/unmute control.

## 🚀 Live on GitHub Pages
To enable GitHub Pages:
1. Go to repository **Settings** → **Pages**.
2. Under **Build and deployment** > **Branch**, select `main` branch and `/ (root)` folder.
3. Click **Save**. Your site will be live at:
   `https://abhi8827shek.github.io/Mama-s-Birthday/`
